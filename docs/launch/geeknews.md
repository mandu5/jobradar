## 본문

매일 아침 채용 사이트 90건을 훑다가, 실제로 읽을 만한 건 3건이라는 걸 깨닫고 만들었습니다.

**하는 일**
- GitHub Actions가 새벽에 사람인·원티드·점핏·링커리어·네이버·라인·우아한형제들 + Greenhouse/Ashby/Lever(당근·쿠팡·Anthropic·OpenAI 등 20여 개 보드) + 신입 리스트 + 공모전을 긁어 JSON으로 커밋
- 스케줄된 Claude Code 루틴이 그 파일을 읽고 `profile/rubric.md`(내 채점표)대로 A/B/C 채점, 한 줄 근거 첨부
- 아침 메일 한 통 + Notion 추적판 행 생성. 마감 D-day도 같이

**설계에서 고집한 것 하나**: 1단계는 **절대 지원하지 않습니다.** 읽고, 채점하고, 보고만 합니다. 내가 추적판에서 "지원예정"으로 바꾼 공고에 한해 2단계가 밤에 지원서 패키지(자소서 초안·글자수 실측·금지표현 grep 체크리스트)를 씁니다. 제출도 사람이 합니다. 찾는 것과 지원하는 것을 한 에이전트에 두면 언젠가 내가 안 냈을 곳에 냅니다.

**왜 Actions와 루틴으로 쪼갰나**: 클라우드 루틴 샌드박스는 외부 사이트 접속이 막혀 있어 수집이 불가능합니다. Actions 러너는 되고요. 그래서 수집은 Actions, 채점은 루틴, 둘은 커밋된 JSON 파일에서 만납니다. `prompts/daily.md`에 이 구조가 만든 사고들이 주석으로 남아 있습니다 — 빈 파일이 커밋되는 바람에 수집기가 "오늘 이미 했다"고 판단해 하루치 다이제스트가 조용히 비어버린 날 같은 것.

**정직하게**
- 원티드는 Actions IP를 403으로 막습니다. 로컬에서만 됩니다
- 채점 품질은 전적으로 rubric에 달렸습니다. 등급이 틀리면 코드가 아니라 rubric을 고칩니다 — 예시 rubric의 규칙 하나하나가 실제로 잘못 채점된 공고에서 나왔습니다
- 스케줄된 Claude Code 루틴이 필요합니다(구독)
- 파서는 사이트 개편에 깨집니다. 대신 저장된 fixture로 테스트해서 CI에서 소리내며 깨지지, 조용히 0건을 내진 않습니다
- **포크는 비공개로 두세요.** 수집 결과가 커밋되니까 공개 포크 = 내 구직 활동 공개입니다. 프로필·지원서는 gitignore로 막아뒀습니다

9/6부터 제 것으로 매일 돌고 있습니다. 한국 포털 커버리지가 필요한 분께 특히 유용할 겁니다 — 해외 도구들(career-ops, ai-job-search)은 이 부분이 없습니다.
