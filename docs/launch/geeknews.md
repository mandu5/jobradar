## 내용 (그대로 붙여넣기)

안녕하세요. 매일 아침 채용 사이트를 90건씩 훑다가 실제로 읽을 만한 건 3건이라는 걸 깨닫고, 그 3건만 골라 메일로 받는 파이프라인을 만들어 9월 6일부터 제 것으로 매일 돌리고 있습니다. 오늘 오픈소스로 올렸습니다.

**가입·키 없이 바로 돌려볼 수 있습니다** (Python 3.10+):

```
git clone https://github.com/mandu5/jobradar.git && cd jobradar
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/python -m radar.collect --only saramin,jumpit
```

오늘 새로 clone해서 돌린 결과: 사람인 150건 + 점핏 32건 수집 → 프리필터·중복 제거 후 102건, 실패 0 (집 회선). 이 단계는 공고 목록을 읽어 로컬 JSON에 쓸 뿐, 아무 데도 로그인·지원하지 않습니다.

**하는 일**
- 새벽에 GitHub Actions가 12개 소스 — 사람인·원티드·점핏·링커리어·네이버·라인·우아한형제들 + Greenhouse/Ashby/Lever(당근·쿠팡·Anthropic·OpenAI 등 20여 개 보드) + 신입 리스트 + 공모전 — 를 긁어 JSON으로 커밋
- 스케줄된 Claude Code 루틴이 그 파일을 읽고 `profile/rubric.md`(내 채점표)대로 A/B/C 채점, 한 줄 근거 첨부
- 아침 메일 한 통 + Notion 추적판 행. 대학원·비자 같은 고정 마감 D-day도 같이

**설계에서 고집한 것**: 1단계는 **절대 지원하지 않습니다.** 읽고, 채점하고, 보고만 합니다. 제가 추적판에서 "지원예정"으로 바꾼 공고에 한해 2단계가 밤에 지원서 패키지(자소서 초안, 글자수는 python으로 실측, 금지표현 grep 체크리스트)를 씁니다. 제출도 사람이 합니다. 찾는 것과 지원하는 것을 한 에이전트에 두면 언젠가 내가 안 냈을 곳에 냅니다.

**왜 Actions와 루틴으로 쪼갰나**: 루틴 샌드박스는 외부 사이트 접속이 막혀 있어 수집이 불가능하고, Actions 러너는 됩니다. 그래서 수집은 Actions, 채점은 루틴, 둘은 커밋된 JSON에서 만납니다. 이 구조가 만든 사고도 `prompts/daily.md`에 주석으로 남겼습니다 — 빈 파일이 먼저 커밋되는 바람에 수집기가 "오늘 이미 했다"고 판단해 하루치 다이제스트가 조용히 비어버린 날 같은 것.

**채점표가 곧 제품입니다.** 등급이 틀리면 코드가 아니라 `rubric.md`를 고치면 다음 날부터 반영됩니다. 예시 rubric의 규칙 하나하나가 실제로 잘못 채점된 공고에서 나왔고, 가장 많이 걸러낸 규칙은 싱겁게도 "모집 직무 목록에 내 직무가 없으면 회사가 아무리 좋아도 C"였습니다. 잘못된 등급 대부분이 직무가 아니라 회사를 채점해서 나왔습니다.

**정직하게**
- 원티드는 Actions IP를 403으로 막습니다. 로컬(집 회선)에서만 됩니다
- 채점 단계는 스케줄된 Claude Code 루틴이 필요합니다(구독). 수집·정리는 어디서든 돕니다
- 채점 품질은 전적으로 rubric 품질입니다. 예시는 템플릿이지 좋은 rubric이 아닙니다
- 파서는 사이트 개편에 깨집니다. 저장된 fixture로 테스트해서 CI에서 소리내며 깨지지, 조용히 0건을 내진 않습니다
- **포크는 비공개로 두세요.** 수집 결과가 커밋되니까 공개 포크는 내 구직 활동을 공개하는 것과 같습니다. 프로필·이력서·지원서는 gitignore로 막아뒀습니다

해외 도구(career-ops, ai-job-search)에는 없는 한국 포털 커버리지가 필요한 분께 특히 유용할 겁니다. 수집기 추가는 파서 파일 하나 + fixture 하나 + 테스트 하나입니다. 피드백 환영합니다.
